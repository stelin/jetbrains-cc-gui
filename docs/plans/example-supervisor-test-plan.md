# 测试任务：在 README 末尾追加一行打招呼

## 目标
在项目根目录 `README.md` 文件的最末尾追加一行 markdown 文本，作为 Supervisor Pair 跑通的烟雾测试。

## 文件范围
- 允许修改：`README.md`
- 禁止修改：所有其他文件

## 步骤

### 步骤 1：读取 README.md 末尾
- 用 Read 工具读取项目根目录的 `README.md`
- 记录文件总行数和最末尾几行的内容
- 验证：能读到文件，文件存在

### 步骤 2：在末尾追加一行
- 用 Edit 工具在文件最末尾追加一行：`<!-- Supervisor Pair test ok -->`
- 不要修改其他任何内容
- 验证：再次 Read 文件，确认最末尾出现了那一行

### 步骤 3：报告完成
- 用一句话总结改动
- 不要执行任何 verify 命令（这是 UI 烟雾测试，不需要外部验证）

## 完成标准
- README.md 最末尾出现新增那行
- 没有其他文件被修改
- 没有调用过 Bash 工具
